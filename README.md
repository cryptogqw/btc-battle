# ⚔️ Crypto War · 多空战场

BTC、ETH 及 Binance / OKX / Coinbase 上 900+ 币种的实时价格 + 多空对决可视化（顶部标签切换 BTC / ETH，「搜索币种」或按 `/` 搜任意币，或用 `?coin=sol` 直接打开）：**蓝军 = 多（买方）**，**红军 = 空（卖方）**。

- **吃单**：主动买入 vs 主动卖出成交额（10 秒 / 1 分钟 / 5 分钟滚动）
- **挂单**：盘口 ±0.5% / ±1% 范围内买盘 vs 卖盘深度 + 深度图
- **战场动画**：前线位置由综合战力（短期吃单 + 1 分钟吃单 + 盘口厚度）决定；每笔大额主动成交化作炮弹 / 重炮 / 巨鲸空袭；单边强势时触发「总攻」
- **数据源**：交易所公共 WebSocket，无需 API Key，纯前端。自动顺序 Binance → OKX → Coinbase，失败自动切换；也可在右上角手动选择，或用 `?source=okx` 参数

纯静态网页（HTML/CSS/JS ES Modules，无构建步骤），部署在 GitHub Pages。

### 战场渲染（WebGL 奇幻战场）

- 默认使用 PixiJS（WebGL）渲染奇幻战场：左边人族（蓝金）城堡与松林，右边兽族（红黑）火山、熔岩与原创黑色尖塔；兵种有剑盾步兵、弓兵（抛物线射箭）、骑兵；大单由人族魔法师的法球、兽族飞龙的龙焰打出，巨鲸单是天降陨火（一颗大陨石带几颗小陨石）。
- 模拟逻辑（前线、兵力、炮弹、爆炸）仍在 `js/battle.js`，WebGL 绘制在 `js/battle-gl.js`，两版看到的是同一场战斗。
- 加 `?fx=classic` 使用经典 Canvas 2D 版；WebGL 不可用或显卡上下文丢失时也会自动退回经典版。
- 军队贴图：人族（蓝金）与兽族（红黑）的步兵、弓兵、骑兵都是手绘精灵动画，用 `tools/3d/pack_sheets.py` 打包成图集 `assets/units/`（WebP，AVIF 兜底；朝左的素材打包时自动镜像；见 [CREDITS.md](CREDITS.md)）。某个兵种图集加载失败时，该兵种退回程序绘制的小人。
- 背景：白天、黑夜两张手绘场景，用 `tools/bg/bg_build.py` 自动切成 天空 / 人族城堡 / 中间山谷 / 兽族要塞 / 地面 几层（`assets/bg/`）。按浏览器本地时间昼夜切换（日出日落按日期估算），太阳、月亮从左往右沿弧线升落，月相按真实日期；晨昏有霞光、光束和暖色调，影子背向光源、太阳越低越长。预览：`?time=18:30` 固定时刻，`?speed=600` 时间加速。
- 远处行军：人族小兵源源不断从城堡台阶口出来往左走出画面，兽族从魔塔脚下的城门出来往右走出画面（去后方列队）；大本营塔楼已撤掉，多/空军旗插在城堡和要塞上。
- 法师与飞龙：投石 / 巨石级大单不再由塔楼抛石，而是人族魔法师在后方现身施放法球、兽族飞龙从要塞飞到前线上空喷火球（巨石级更大）；总攻时进攻方的法师 / 飞龙出阵并定时施法。巨鲸单是天降陨火。胜利时人族是金色圣光迸发、兽族是熔岩火焰喷发。
- 性能：画质三档自动切换（手机默认中档；连续掉帧降档、长期流畅升档；`?q=low|mid|high` 可强制）；战场滚出屏幕时暂停绘制，120Hz 高刷屏隔帧绘制；军队图集统一为 WebP；白天/黑夜背景另一张在临近晨昏时才加载。
- 音效：魔法师施法是上行的水晶琶音，飞龙喷火是低沉颤动的龙吼加喷火声，法球 / 火球落地再一声爆炸（大单扎堆时限流）；巨鲸是陨石呼啸坠落后的巨响和火焰噼啪声。全部实时合成。
- PixiJS 已打包在 `js/vendor/pixi.js`（按需动态加载，约 170KB gzip），重新打包运行 `./tools/build-pixi.sh`。

## 战力模型（全部来自实时行情）

前线位置 = 价格涨跌 50%（10 秒 25% + 1 分钟 25%）+ 吃单 30%（10 秒 15% + 1 分钟 15%）+ ±0.5% 挂单厚度 20%。
炮弹/重炮/巨鲸空袭只由真实主动成交触发，大小按成交额；前线士兵开火频率与该方近 10 秒主动成交额成正比；
「总攻」「大获全胜」只在综合战力越过阈值（并持续 20 秒）时出现。随机数只用于位置抖动等纯视觉效果。
页面上的「战况依据」实时显示这些输入。

音乐：默认开启（浏览器要求先点击一次：开场「⚔️ 点击进入战场 🔊」或页面任意处）。Web Audio 实时合成（无外部音频文件），全部由行情驱动、无随机定时：
- 速度 BPM ← 近 10 秒成交额 + 成交笔数（总攻时 ≥124）
- 明暗调 / 铜管上行或下行 ← 10 秒、1 分钟价格涨跌（为主）+ 战力
- 价格每跳一下弹一个音：涨则音阶上行，跌则下行
- 每笔大单（≥ 炮弹阈值）一声炮响；巨鲸、总攻、胜利有专属音效
- 顶部（手机为右下角）实时显示「♪ BPM · 战况」

部署前运行 `./stamp.sh` 更新 CSS/JS 版本号，避免浏览器缓存旧文件。
